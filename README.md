## Design Principles
- High agentic autonomy (Discovery Agent decides what layers and sources to pursue)
- Mobile-first PWA — designed to be added to iPhone Home Screen
- Model-agnostic (no lock-in to Grok, Claude, GPT, Gemini, etc.)
- Public / open data only, with strict source-health and truth labeling
- Transparent research signals only — never real brokerage orders
- Early GitHub deposit so work is not lost to token limits
